# Cloud DMA for Destiny 2

Cloud DMA is the infrastructure piece most buyers need explained first. Despite the name, this listing is not a second gaming PC plus external DMA hardware kit.

The product uses a Hyper-V-based virtual environment on a single Windows PC. It is an activation and runtime layer for the provider stack—not the Destiny 2 cheat license itself.

## Cloud DMA for Destiny 2: what is included?

Cloud DMA provisions the virtual environment through Hyper-V on the same machine and uses an encrypted service link for activation. The listing does not require a second tower, USB DMA bridge, or PCIe DMA card.

For Destiny 2, Cloud DMA is required for full functionality on supported builds. Buying Cloud DMA alone does not include the Destiny 2 feature package—you still need the main license.

## Cloud DMA single-PC setup

Setup targets one gaming PC with [Microsoft Hyper-V](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/hyper-v-overview), Intel VT-x or AMD-V enabled in firmware, and Windows 10/11 64-bit. Pro, Enterprise, and Education editions are recommended.

Also listed:

- 8 GB RAM minimum (16 GB recommended).
- Stable broadband.
- HVCI, Core Isolation, TPM, and Secure Boot enabled.

Edition-specific Hyper-V availability varies—verify before you pay. Deep checklist: [Windows settings for Cloud DMA](/cloud-dma-requirements/).
