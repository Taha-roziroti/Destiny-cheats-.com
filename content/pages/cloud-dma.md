# Cloud DMA for FragPunk

Cloud DMA is probably the part of this setup that needs the most explanation.

The name can make it sound like you're buying an external hardware device, setting up another gaming computer and connecting a bunch of equipment. That's not how this particular product is described.

The supplied Cloud DMA product uses a Hyper-V-based virtual environment on a single Windows PC. It's an infrastructure layer used by the provider's software stack, not the FragPunk license itself.

Let's separate the pieces so you know what you're paying for.

## Cloud DMA for FragPunk, what's actually included?

The Cloud DMA product is described as an installation and activation layer that provisions a virtual environment through Hyper-V on the same computer.

According to the provider, the setup doesn't require a second physical tower, USB DMA bridge or PCIe DMA card.

The installation also uses an encrypted service link for activation.

That distinction matters. Traditional external hardware setups and this single-PC arrangement aren't interchangeable descriptions. When you're buying this product, you're purchasing the specific Cloud DMA layer listed by the provider.

For FragPunk, Cloud DMA is required for full functionality on supported builds.

You still need the separate FragPunk license. Buying Cloud DMA by itself doesn't mean you've purchased the entire FragPunk feature package.

## Cloud DMA single-PC setup

The setup is designed around one gaming PC.

It uses Hyper-V to create the required virtual environment, with CPU virtualization enabled through the system firmware. The listed processor virtualization options are Intel VT-x and AMD-V.

Windows 10 and 11 64-bit are listed as supported operating systems. Windows Pro, Enterprise and Education editions are recommended for Hyper-V availability, with the provider advising buyers to follow the installer notes for their specific edition.

The listing also specifies:

- At least 8 GB of system RAM.
- 16 GB RAM recommended.
- Stable broadband internet.
- HVCI enabled.
- Core Isolation enabled.
- TPM enabled.
- Secure Boot enabled.

The exact compatibility of an individual Windows edition should be checked before purchasing. Don't assume that every Windows installation has the same Hyper-V availability.
