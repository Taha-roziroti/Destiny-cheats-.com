# Cloud DMA Requirements for Windows 10/11

Before buying Cloud DMA for a Destiny 2 setup, confirm your PC can run the Hyper-V-based install. Windows edition, CPU virtualization, memory, and security settings all matter.

Use this checklist while you inspect your system.

## Cloud DMA requirements: Windows and Hyper-V

Supported OS list: Windows 10 and Windows 11 64-bit. The installer uses the [Windows Hyper-V role](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/hyper-v-overview). Pro, Enterprise, and Education are recommended for Hyper-V availability.

Follow installer notes for your edition. Home and uncommon builds may need extra confirmation before purchase.

## CPU virtualization and Hyper-V requirements

Your CPU must support and enable:

- Intel VT-x, or
- AMD-V

Microsoft’s [enable Hyper-V on Windows](https://learn.microsoft.com/en-us/virtualization/hyper-v-on-windows/quick-start/enable-hyper-v) guide covers firmware and role steps. Supported silicon is not enough if virtualization is still off in BIOS/UEFI.

## Cloud DMA Windows 11 and memory requirements

| Component | Requirement |
|---|---|
| System RAM | 8 GB minimum |
| Recommended RAM | 16 GB |
| Internet | Stable broadband connection |
| CPU virtualization | Intel VT-x or AMD-V |
| Virtualization platform | Hyper-V |

Broadband is required for encrypted activation and ongoing service connectivity.

## Security settings to check

Confirm these are enabled:

- HVCI.
- Core Isolation.
- TPM.
- Secure Boot.

Use the provider’s current setup docs for the exact clicks on your Windows build and firmware.

## Additional purchases you need

Cloud DMA also lists three separate required purchases: GREENWARD, Static Server, and AWS. None is included in the Cloud DMA license price.

For product context see the [single-PC Cloud DMA explainer](/cloud-dma/). For license math see [Destiny 2 plan pricing details](/destiny-cheats-price/). Feature summary lives on the [PC Destiny 2 cheats homepage](/).

If virtualization, Hyper-V, or security settings fail the checklist, resolve that before checkout.
