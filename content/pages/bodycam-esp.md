# Bodycam ESP and Wallhack Features

There's quite a bit more to player ESP than switching on one overlay and calling it a day.

The Bodycam product listing includes several visual options, from player boxes and skeletons to health indicators, distance and color customization. It also names Drone ESP and Bomb ESP as separate features.

Let's break down what's actually listed, because a feature menu is much more useful when you know what you're looking at.

## Bodycam ESP: What the Visual Options Include

The current product page groups several visual settings together.

### Player ESP and Box ESP

Player ESP and Box ESP are both listed in the visual options.

They appear as separate entries in the feature list, so they're worth checking individually in the current menu.

### Skeletons and Snaplines

The package also lists skeletons and snaplines.

These are separate visual options rather than one combined setting. The listing doesn't specify every available style or adjustment range, so those details are [NEEDS INFO].

### Nicknames, Health and Distance

The visual menu includes three more useful-to-identify entries:

- Nicknames.
- Health bar.
- Distance.

These are listed as individual features. If you're comparing visual menus between products, check whether those specific entries are included instead of relying on a generic ESP label.

### Team Check

Team check also appears in the current visual feature list.

It's worth confirming the available configuration in the live interface before purchasing, especially if you're looking for a particular team-filtering behavior.

## Chams and Other Visual Settings

The product page lists three chams options:

- Player Chams.
- Local Chams.
- Weapon Chams.

There's also full color customization under the miscellaneous options.

That gives the visual section more than a single fixed presentation. However, the product listing doesn't provide a complete color palette or specific customization limits, so we won't make those up.

## Drone ESP and Bomb ESP

Two more entries deserve their own mention.

The published list includes Drone ESP and Bomb ESP. These are named separately from the regular player visual options.

If you're interested in either one, make sure the current product listing still includes it when you check out. Features and compatibility details can change as the game receives updates.

## What Else Comes With the Package?

ESP is only one part of the full Bodycam product.

The same listing includes an aimbot section with head and chest targeting, FOV circle, aim line, silent aim, magic bullets and other aim-related options.

There are also movement and weapon entries, including custom view FOV, gravity multiplier, fly hack, third person, no recoil, rapid fire and full auto.

You can review those on the [aim configuration options overview](/bodycam-aimbot/), or head back to the [full Bodycam cheats overview](/).
