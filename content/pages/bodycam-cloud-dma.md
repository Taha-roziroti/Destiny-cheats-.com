# Bodycam Cloud DMA: What It Is and What You Need

Cloud DMA is probably the part of the Bodycam setup that deserves the most attention before you place an order.

Why? Because it has its own product page, its own system requirements and several separately required components.

The Bodycam listing says Cloud DMA is required for full functionality on supported builds. So if you're checking the total setup cost, don't stop at the price of the main Bodycam package.

Here's what the supplied product information actually says.

## Bodycam Cloud DMA: Why It's Listed as Required

The Cloud DMA product is described as an infrastructure layer for the provider's software catalog.

According to the current listing, its setup uses a Hyper-V-based virtual environment on a single gaming PC. Activation is completed through an encrypted service link.

That's worth spelling out because the name can make people assume they need another computer or a physical DMA card.

The supplied product page specifically describes a single-PC setup. It says you don't need a second physical tower, a USB DMA bridge or an external PCIe DMA card for this particular setup.

If you're buying the Bodycam package, check the live listing to confirm the applicable Cloud DMA requirement for your supported build.

## Single-PC Setup and Hyper-V Requirements

The Cloud DMA product page lists several technical requirements.

Here's the current published checklist:

- Windows 10 or Windows 11, 64-bit.
- HVCI enabled.
- Core Isolation enabled.
- TPM enabled.
- Secure Boot enabled.
- Intel VT-x or AMD-V virtualization enabled in firmware.
- Ability to enable the Hyper-V role.
- At least 8 GB system RAM.
- 16 GB RAM recommended.
- Stable broadband internet.

The listing recommends Windows Pro, Enterprise or Education for the Hyper-V setup, with the instruction to follow the installer's notes for the specific Windows edition.

Don't assume every Windows installation has the same virtualization options available. Check your edition and firmware settings first.

This is the bit people can easily miss.

## Does Cloud DMA Need a Second Computer?

Not according to the supplied product listing.

The advertised setup is based on one Windows gaming PC and Hyper-V. The page specifically says that a second physical tower or external DMA box is not part of this setup.

The CPU needs virtualization support, and the Windows installation must be capable of running the Hyper-V role.

That's a much more useful thing to know before buying than discovering the hardware requirements halfway through installation.

## How Does It Relate to the Bodycam Package?

The Bodycam product listing includes Cloud DMA as a requirement for full functionality on supported builds.

The two listings should be treated as separate purchases unless the live checkout explicitly says otherwise.

Cloud DMA isn't a product I'd recommend buying without reading its requirements first.

Confirm your Windows edition, check that CPU virtualization is available, review the Hyper-V notes and account for GREENWARD, Static Server and AWS in your budget.
