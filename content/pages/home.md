## What makes the FragPunk setup different?

Here's the part you should understand before buying.

The full FragPunk setup uses Cloud DMA. It's listed as a requirement for full functionality on supported builds, so don't treat it as an optional extra that you can ignore after purchasing the main license.

Cloud DMA is a separate product. Its setup uses a Hyper-V-based virtual environment on a single Windows PC, rather than the usual arrangement involving a separate computer and external DMA hardware.

There are also additional services required for that setup: GREENWARD, Static Server and AWS. These are purchased separately.

That deserves a proper mention because the price of the FragPunk license alone doesn't represent the complete setup cost.
